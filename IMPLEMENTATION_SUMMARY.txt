✅ EXAMPLE: How Data Isolation Works

Database query (in /api/clusters):
```sql
SELECT * FROM public.clusters 
WHERE user_id = auth.uid() 
AND project_id = $1;
```

Result:
- User A sees only clusters they created
- User B sees only clusters they created
- No cross-user data leakage
- Enforced at database level (RLS policy)
